# CareAxis – Healthcare Navigation Platform

## Project Overview

CareAxis is a responsive healthcare navigation website developed as part of a Front-End Developer Intern assessment for Ourea. The project focuses on creating a user-friendly interface that helps people explore healthcare services and understand the process of planning medical treatment in India.

The website is built with React and React-Bootstrap


## Technologies Used

- **React.js** – Building the user interface with reusable components.
- **JavaScript (ES6+)** – Component logic and interactivity.
- **React-Bootstrap** – Responsive layouts, navigation, buttons, and UI components.
- **Bootstrap 5** – Grid system, spacing utilities, flex utilities, and responsive classes.
- **HTML5** – Structuring the interface.
- **CSS3** – Custom styling
- **Vite** – Development server and build tool.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone <your-github-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder-name>
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal, usually:

   ```text
   http://localhost:5173
   ```

## Design and Technical Decisions

- Used React components to organize different sections of the website.
- Used React-Bootstrap and Bootstrap utility classes to build responsive layouts with minimal custom CSS.
- Used reusable components to keep the code organized and easier to maintain.
- Used responsive grid and flex utilities to support different viewport sizes.
- Added subtle hover transitions to buttons and interactive cards to improve usability.
- Used local image assets to maintain consistency with the provided design reference.
